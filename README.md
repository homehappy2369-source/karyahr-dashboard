# KaryaHR Dashboard

buatkan aplikasi dashboard hrd yang berguna untuk memudahkan pekerjaan dan memantau kinerja karyawan,sistem gaji dll,nantinya aku akan masukan ke aapanel dan menggunakan database mysql untuk desain warna biru muda dan putih

Fitur apa saja yang perlu ada di versi pertama?: Data karyawan (Profil, jabatan, divisi dan status kontrak), Penggajian (Gaji pokok, tunjangan, potongan dan slip gaji), Penilaian kinerja (KPI, skor bulanan dan catatan atasan), Absensi (Kehadiran harian, keterlambatan dan lembur), Cuti & izin (Pengajuan dan persetujuan cuti, sisa jatah cuti), Rekrutmen (Lowongan, data pelamar dan tahap seleksi), Laporan & ekspor (Rekap gaji, absensi dan kinerja ke Excel/PDF), Hak akses pengguna (Login admin, HRD, manajer dan karyawan)

Layar utama paling sering dipakai untuk apa?: Proses gaji (Hitung dan terbitkan gaji bulanan dengan cepat)
